Choose the first nontrivial state in each existing dataset by the already
declared metadata order. Select its minimum previously computed two-vector-span
bound across its five sampled future pools. Publish the selected coordinates,
input/source hashes and this protocol BEFORE either new true response. Solve

samples. Compare each response and its stored trial bound with the completed
baseline endpoint minus the original dataset margin. This separates a weak
point bound from an overly broad full-pool superset at those two witnesses only.

material. Retain all60 metadata states; skip17 action-alias-only states from the

contexts, use only the initial observed X/y, stored fixed kernel hyperparameters,

expose the first-action response until the action set has been constructed.

With one unknown nonnegative response z, the fixed-kernel, target-normalized
posterior mean is affine in z. Compute slope/intercept error enclosures using
a verified inverse-residual norm bound on the computed binary kernel matrix.
Intersect relaxed pairwise affine inequalities on [0,infinity) and on the
already available trial-bound response range. Outward arithmetic and rational
infeasibility checks protect exclusions; unresolved constraints retain candidates.
Keep all ties, including isolated boundary actions. An inverse-residual failure
returns the full pool. The conditional model does not certify transcendental
kernel errors, native prediction errors for every possible z, or physics errors.
