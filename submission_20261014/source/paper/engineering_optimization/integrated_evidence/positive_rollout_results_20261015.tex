
\section{Earlier implementation and supporting certificate evidence}\label{sec:positive_results}

\subsection{Setting and minimum sufficient comparison}

The existing EngiBench Beams2D v1 workflow \citep{ref23} uses a symmetric MBB beam with $100\times50$ bilinear elements, SIMP exponent 3, stiffness limits $10^{-9}$ and 1, and Poisson ratio 0.3. Nineteen effective logits and an anchor define a $4\times5$ coarse density field interpolated to the mesh; a logistic shift fixes mean density at 0.35. Smaller compliance is preferable. This is one deterministic structural-design family.

Both ten-group datasets retain 60 metadata states: 17 alias-only states and 43 nontrivial states containing 114 first-action branches, with eligible pools of 1024 designs. All have already been observed in development. The former holdout name does not create an unseen validation set for the present method. The incumbent equals the minimum of each state's stored training responses.

The comparison asks whether the implemented solver meets its numerical selection guarantee and whether local stability avoids complete projections under the same objective and precision. The direct route uses the same posterior enclosures, conditional integrator, tolerance and fresh reader, while always constructing the complete projection. Paid two-step outcomes separately address engineering consequences under the same continuation. No extra dataset, parameter sweep or independent optimization run is added.

\subsection{Prospective source freeze and arithmetic scope}

The new v2 code, protocol and all 43 training/parameter input snapshots were saved before execution in commit \texttt{f4f352acdb5ccbc98ead05455d2083ccc72acca3}. It is a new implementation, not recovery of the missing earlier positive-response program. Exactly one paired pass alternates method order by state. There are 86 method/state runs, without selecting a favorable repetition.

Fixed binary $A/B/K$, outward logarithms, inverse-residual and positive-definiteness gates, and MPFR 4.2.1 at 192 bits define the arithmetic scope. Exported interval endpoints are rounded outwards to binary64. The normal window is $[-8,8]$, with an explicit tail and no renormalization. Limits were fixed at 32,768 refinements and 30 s per method/state, and 600 s for the comparison. No limit or tolerance was adjusted after the results.

Seven necessary program-test groups cover directed rational arithmetic, normal identities, independent conditional integration, normal-weighted integration, exact ties, corrupt-certificate rejection, and a separate exact two-by-two posterior oracle. Engineering execution reconstructs every raw-response selector with matching frozen coefficients and kernel/cross hashes. Complete projections must match the previously verified exact nonnegative domains; this reuses those domains as frozen inputs and does not rerun the old full exclusion-proof suite.

The reader freshly checks local dominance, cell assignments, disjoint coverage, summation and selection. It shares the interval and curvature implementation with the producer. It is not a fully independent arithmetic implementation. Kernel-function evaluation, statistical calibration and physical/PDE error are outside the certificate.

\subsection{Subsequent regional certificate transformation}\label{sec:regional_results}

It reuses 89 fixed-continuation certificates; 25 complete-projection branches retain their original checked intervals. A hash-identified input freeze precedes conversion. No GP reconstruction, conditional-reward evaluation, full projection, physical call or new optimization sample is performed.

Four additional mathematical checks cover the capped marginal moments, weighted low-tail bound, whole/partial leaf conversion and invalid-input rejection. Each original leaf remains an accepted v2 input, not an independently reconstructed proof. Across all 43 states, all 114 transformed-or-retained branch intervals contain the same ordinary point-parameter references. All original selections remain accepted, as expected from valid interval intersection; this is not independent confirmation.
