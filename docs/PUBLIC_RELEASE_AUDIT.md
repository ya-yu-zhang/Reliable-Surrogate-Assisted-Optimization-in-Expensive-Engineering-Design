# Public Release Audit

Audit date: 2026-09-30

The staged public file set was checked before its first push.

- No API keys, access tokens, passwords, private keys, credential files, or
  GitHub/OpenAI-style secret patterns were detected.
- No user-profile paths, Codex attachment paths, or private local usernames
  remain in the public file set.
- No staged file exceeds GitHub's 100 MB per-file limit.
- Virtual environments, raw results, downloaded papers, third-party author
  source trees, interrupted-run archives, build logs, and temporary files are
  excluded.
- Publisher templates, journal class assets, and assembled submission bundles
  are excluded because this repository does not grant redistribution rights.
- The repository intentionally has no open-source license at this revision;
  copyright remains with the authors.

This audit concerns accidental disclosure and repository hygiene. It does not
replace institutional review of authorship, data ownership, export controls,
or journal preprint policy.
