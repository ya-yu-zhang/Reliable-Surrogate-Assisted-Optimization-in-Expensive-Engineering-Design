# 条件期限审计：实现合同与信息边界

本文件根据已经冻结的v1代码和原始记录整理，供作者核实方法描述。它不改变原实验协议、不提出新优化器，也不把技术规范自动认定为足够的期刊创新。

## 输入与目标

| 对象 | v1实现 | 核查位置 |
|---|---|---|
| 冻结状态s | 100个自有训练标签、在共享50标签状态拟合后固定的核参数、根候选池、动作映射 | engineering_optimization_budget_audit.py的state_frozen、*_plan.json |
| 真实目标上下文c | 目标实现、物理工况、参数化、网格、材料和边界配置 | pre记录中的context；跨网格不可仅以相同19维参数复用响应 |
| 第一动作a | mean/EI/PI/LCB在同一冻结模型和候选池上的选择 | root_decisions、classes、actions、mapping |
| 续跑规则r | 每条分支自己的标签更新；相同的mean或EI规则及候选种子流 | trajectories、common_continuation_choices |
| h0与H | h0为首次干预，H=5表示再执行五次共同规则动作 | 每条完整分支有0--5六条记录 |
| 初始尺度 | 该状态的初始最优柔度m_init>0 | initial_best |
| 判断量 | d_j(H)=(m_baseline(H)-m_j(H))/m_init | classify及analyze_budget_audit.evaluate |
| 门槛 | 主门槛tau=0.001；其余0.0001、0.01为预定描述性敏感性 | relative_margin、margin_sensitivity |
| 审计预算B | 每个状态的响应请求预算，包括精确缓存读取；主B=18 | audit_budget、audit.trace |

训练标准差归一化的原一步诊断与本合同的初始柔度归一化期限目标不同；不同实验不能因使用相似策略名称而合并成完全相同的重复。

## 等价与输出

- 精确响应等价：同一确定性目标上下文和同一精确设计点。复用已知响应时，原信息不能提前进入冻结根模型。
- 整条分支等价：还要求相同冻结历史、核参数、第一动作、续跑规则和种子流。v1在同一状态内合并相同第一动作；它没有授权跨不同历史合并整条轨迹。
- 结构等价输出：与基线完全相同的分支可返回tie，原因exact_same_action_and_continuation。
- 测得期限输出：两条非别名分支均到达H，返回better/tie/worse，原因measured_target_horizon。这是测量结果，不是对未来响应的统计预测保证。
- 一步代理输出：h0结果仅预测所声明h5目标，原因h0_proxy_for_h5_not_certificate。
- 暂缓输出：任何所需分支未完成目标期限，返回abstain，原因budget_insufficient_for_target_horizon。立即收益相同不允许提前认证后来相同。

## 预算容量诊断

在完整分支认证、所有前缀/缓存读取均计费的合同下，K个精确动作类、期限H和预算B最多完成

`C_max = min(K-1, max(0, floor(B/(H+1))-1))`

个非基线动作类对照。共享基线也必须完整，K=1没有非基线对照。这个指标只依赖冻结后的动作类和预定预算，不需要读取h5响应。它是该计费模型的基础容量计算，不是额外物理求解次数下界，不适用于有额外有效边界可以提前认证的审计，也不作为主要理论创新。

本组30状态的类数分布是13个K=1、9个K=2、8个K=3。H=5时，B=18已可完成全部25个非基线动作类对照。B=12容量为9+8=17；固定深度达到17，自适应只完成9。K=3状态的自适应先读每类h0/h1，再完成基线，留下不足以完成一个替代分支的预算。这解释覆盖差异，不证明按固定深度选出的对象更有工程价值。

固定深度顺序反转后，B=12覆盖仍为17/25，但每种续跑有8个状态改变被判断的动作类。EI的较差对照可能未判断；没有阳性目标的样本不能验证避免遗漏有价值动作的能力。

## 成本与复制

响应请求、各状态训练档案外的不同点、跨状态目标缓存和实际物理尝试分别计数。各状态新点数求和不等于全工作流的独特物理调用数。独立研究收集2134次付费尝试，整个修订累计55305次；这些数字不能当作单个部署审计的成本或节省。

新增顺序与容量分析不拟合GP、不调用物理求解、不修改frozen_files或原标签。分析观察过的完整记录，因此是事后描述性分析。任何据此改造的方法都需要另行冻结与独立验证。
