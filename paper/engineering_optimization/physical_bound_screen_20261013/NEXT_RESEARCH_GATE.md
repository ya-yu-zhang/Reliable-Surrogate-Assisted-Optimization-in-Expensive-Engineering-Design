# The next research gate after the failed two-reference screen

This is a technical research specification, not a manuscript argument or a
frozen new physical experiment. The complete1720-point screen has already
disqualified root-tie sharpness for this two-reference/full-pool operator.

## Separate point-bound weakness from candidate-set pessimism

Before acquiring a large trial basis, specify a small true-response diagnosis
on representative witness points. Choose the first nontrivial state by the
declared metadata order in each dataset, then its minimum computed span-bound
witness. Publish that selection and its paid-attempt cap BEFORE reading those
witnesses' true responses. Those choices are development cases, not independent
positive validation. Do not silently amend the original two-reference cost cap.

- If a witness's actual response is below C-tau*m_init, even its exact response
  makes the declared full-pool envelope too small. A larger displacement basis
  cannot repair that particular superset; a smaller provably reachable set is
  needed.
- If its actual response is above that level while its trial lower bound is far
  below it, the point-bound approximation is a limiting factor at that witness.
  This does not establish that a better basis suffices for the whole pool.
- Neither result proves failure of all later-prefix certificates or all audit
  targets. Retain the distinction between category and selected-branch costs.

These additional true-response evaluations have NOT been performed in this
release. The original two reference attempts and all their outputs remain
unchanged.

## A concrete candidate information increment: GP action reachability

For posterior-mean continuation with FIXED kernel hyperparameters, noise setting
and a fixed augmented input history, write W=k(K+alpha*I)^(-1). With normalized
targets, its predictive mean still has the form

\[
\mu = W y + (1-W\mathbf{1})\bar y.
\]

With one as-yet-unobserved response z, each candidate mean is affine in z. A
candidate can be the next action only where all its pairwise affine inequalities
are satisfied within a valid response range. An explicitly computed outer set
of such actions could reduce bound queries relative to all1024 candidates.
This is a proposed next operation, not an implemented or validated certificate
here. Basic affine-envelope reasoning is not a new theorem.

The first executable validation should compare that reachable-set operation
with the same-state full-pool bound reader, given identical available bounds.
Check inclusion of every actual next action, numerical boundary/tie handling,
construction time and bound-query cost. Use whole observed seed groups as
development. An outer set must include numerical uncertainty; approximate
infeasibility alone cannot exclude an action. A narrower set is useful only if
its downstream category/selection bounds actually sharpen at an acceptable cost.

The affine argument does not transfer directly to EI/PI, target-standardized
uncertainty, refitted hyperparameters or arbitrary adaptive continuation. Longer
H needs a reachable-history construction, not a claim based only on a one-step
candidate reduction. Do not sell a shorter-horizon result as H=5 certification.

## Stop/go for a subsequent independent study

Independent experiments remain conditional on an implemented, validated
information increment. Freeze the target horizon, engineering margin, inclusion
rule, response-cost model, strongest simple comparator and complete seed groups
before new labels. Compare errors, abstentions, coverage, selection loss and
complete costs, including physical/bound setup, GP work and selected completion.
If no increment passes, retain the narrow diagnostic paper positioning and its
innovation risk; additional same-model seeds or extra reference vectors alone
do not resolve it.

## Engineering target and margin gate

The current backend applies one nodal vertical load and one nodal vertical
support, alongside the left-boundary horizontal supports. Before attempting
physical convergence certification, test the effect of those load/support
footprints and density mapping. A finite physical load/support patch held
constant across meshes would define a new engineering objective; it cannot be
substituted into historical labels or cache contexts. No cause of the observed
absolute mesh variation is certified here. Choose an engineering benefit margin
only after the new target and numerical resolution have a defensible basis.
